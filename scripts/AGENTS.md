# scripts 모듈

이 모듈은 `doc/` 원본을 읽어 배포용 `public/content/` JSON과 WAV를 만드는 로컬 준비 도구를 소유한다. 브라우저 앱을 변경하거나 런타임 서버를 만드는 것은 이 모듈의 범위가 아니다.

`.env`의 `GEMINI_API_KEY`는 이 모듈에서만 읽을 수 있고, 값·요청 헤더·원본 이외의 민감 정보를 출력하면 안 된다. 기존 한국어 번역은 보존하고 누락된 번역만 생성한다. 재실행 시 같은 문장 보강과 이미 있는 WAV는 건너뛴다.

지문 ID와 오디오 경로는 결정적이어야 한다. 모든 `doc/*.txt`는 제목을 파일명에서 얻어 지문 목록에 포함한다. 준비 도구를 바꾸면 TypeScript 검사와 실제 단일 화자 WAV 생성으로 API 형식·출력 경로를 확인한다.
