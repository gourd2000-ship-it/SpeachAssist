# 비밀 값과 배포

`GEMINI_API_KEY`는 개발자 로컬의 `.env`에만 존재하며 콘텐츠 준비 도구의 서버 측 Node 실행에서만 읽는다. `.env`와 생성 로그는 Git 추적 대상이 아니어야 하며, 키 값은 터미널 출력·문서·오류 메시지에 기록하지 않는다.

브라우저 번들과 `public/content/`에는 지문, 번역, 발음 표기, WAV만 포함할 수 있다. 브라우저 앱에서 Gemini SDK를 추가하거나 API 키를 전달하거나 원문을 외부로 전송하면 안 된다.

이 앱은 로그인, 개인 정보, 학습 기록, 권한 체계를 다루지 않는다. 정적 파일을 공개 배포하므로 지문과 생성된 학습 자료는 공개 가능한 내용만 넣어야 한다.
