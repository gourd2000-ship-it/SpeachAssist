# 학습 규칙

지문은 한국어 번역 한 줄 다음 영어 문장 한 줄의 순서를 기본으로 하며, 빈 줄은 무시한다. 한국어 줄 없이 등장한 영어 문장과 빈 한국어 줄 뒤의 영어 문장은 번역 생성 대상이다. 영어 문장 없이 남은 한국어 줄과 영어 문장이 전혀 없는 파일은 유효하지 않다.

원본에 제공된 한국어 번역은 그대로 사용해야 하며, 생성 결과가 덮어쓰면 안 된다. 한글 발음은 번역이 아니라 영어 소리에 가깝게 표기한 별도 값이다.

보기 상태는 영어만, 번역 표시, 한글 발음 표시 중 하나다. 번역과 한글 발음은 동시에 표시될 수 없고, 켠 보조 정보는 해당 영어 문장 바로 아래에만 나타난다.

문장과 단어는 별도 재생 대상이다. 단어 비교는 대소문자와 주변 문장부호를 무시하고, 축약형은 하나의 단어로 유지하며 하이픈은 단어 경계다. 새 문장 또는 단어를 재생하면 이전 재생은 즉시 중지된다. 다시 읽기는 마지막 대상으로 처음부터 재생하고, 중지는 현재 재생을 처음으로 되돌린 뒤 끝낸다.
