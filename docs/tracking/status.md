# 현재 상태

## 완료

- React 정적 앱에서 지문 목록을 읽고 영어 문장을 표시한다.
- 번역과 한글 발음 표기는 기본적으로 숨기며 상호 배타적으로 전환한다.
- 문장 버튼은 저장 WAV를, 클릭 가능한 단어 버튼은 브라우저 내장 TTS를 같은 재생 제어로 사용하며, 중지·다시 읽기·재생 실패 알림을 제공한다.
- 지문 파싱, 경로 생성, 단어 분리, 화면 상호작용 검사가 구현되어 있다.
- `sample2` 서울 여행 지문(39문장)의 번역, 한글 발음, 문장 WAV와 정적 콘텐츠가 준비되어 있다.
- 콘텐츠 준비 중 실패해도 기존 공개 콘텐츠를 보존하도록, 임시 생성·검사 후 교체와 회귀 검사가 구현되어 있다.

## 남은 범위

- 앱 안에서 지문·번역·발음 표기를 편집하거나 추가하는 기능
- 개인별 학습 기록, 동기화, 반복·속도·음성 선택 같은 맞춤 기능
- 복잡한 다국어 원본 형식과 여러 언어의 발음 표기 지원
