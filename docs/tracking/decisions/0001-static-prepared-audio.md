# 정적 준비형 음성

## 배경

자연스러운 Gemini 음성을 원하지만, 학습할 때마다 API 비용과 키 관리 부담이 생기면 공개 웹앱의 운영비가 커진다.

## 결정

지문을 준비할 때만 Gemini로 번역·발음 표기·문장·단어 WAV를 생성하고, 배포 앱은 저장된 결과만 읽는다.

## 대안

브라우저가 재생 시 Gemini를 호출하는 방식은 매 사용 비용과 키 노출 위험이 있어 선택하지 않았다. 브라우저 기본 음성 합성은 추가 API 비용은 없지만 음질을 Gemini 수준으로 맞추기 어렵고, 기기별 결과가 달라 선택하지 않았다.

## 결과

지문 변경 때 사람이 준비 명령을 실행해야 하고 저장 WAV 용량이 늘어난다. 반대로 공개 앱은 서버·로그인·런타임 생성 비용 없이 정적 호스팅할 수 있다.
