# 단어 내장 TTS

## 배경

단어마다 Gemini WAV를 준비하면 지문 길이에 비례해 생성 요청과 저장 용량이 늘어난다. 준비가 일일 TTS 요청 한도에서 중단되면 일부 단어 버튼이 존재하지만 재생할 WAV가 없는 불완전한 지문이 배포될 수 있다.

## 결정

문장만 Gemini로 WAV를 생성한다. 단어 버튼은 브라우저의 `SpeechSynthesis`로 영어 단어 하나를 재생하며, 새 문장·단어 재생과 지문 전환은 진행 중인 WAV 또는 내장 TTS를 중지한다.

## 결과

단어 재생은 추가 API 요청·키·정적 WAV 없이 동작한다. 대신 음색과 발음 품질은 사용자의 브라우저·운영체제에 설치된 영어 음성에 따라 달라질 수 있다.
