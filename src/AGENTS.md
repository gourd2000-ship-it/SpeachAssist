# src 모듈

이 모듈은 브라우저에서 지문 JSON을 읽고 화면·재생 상호작용을 제공한다. 콘텐츠 준비나 API 키 관리는 이 모듈의 범위가 아니다.

`content/`는 원문 파싱, 문장·단어 정규화, 정적 JSON 조회를 소유한다. `audio/`는 한 번에 하나의 브라우저 오디오만 재생하고 새 대상이 이전 대상을 중지하도록 보장한다. `App.tsx`는 보기 상태, 지문 선택, 접근 가능한 제어를 조합한다.

문장 앞 버튼은 문장 WAV만, 영어 단어 버튼은 단어 WAV만 재생해야 한다. 번역과 한글 발음은 동시에 렌더링하면 안 된다. 새 재생 대상이나 지문 선택은 기존 재생을 멈춰야 한다.

화면 동작을 바꾸면 재생 대상, 실패 알림, 토글 배타성, 키보드로 접근 가능한 버튼 이름을 Vitest로 검사한다. 저장 콘텐츠의 형식을 바꿀 때는 `scripts/`를 수정하지 않은 채 브라우저 쪽에서 임시 변환하지 않는다.
